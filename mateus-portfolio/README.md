# 🚀 Portfólio Profissional — Mateus Junio da Silva

Repositório do meu portfólio profissional, desenvolvido para apresentar minha trajetória acadêmica, competências técnicas e projetos nas áreas de **modelagem 3D, análise de cargas estruturais e engenharia aeroespacial**, além de projetos de IoT, automação e sistemas embarcados.

🌐 **Acesse o portfólio:** https://mateus-eng.vercel.app/

## 🎯 Objetivo

Centralizar meus projetos e experiências em uma plataforma que demonstre minhas habilidades em engenharia, desenvolvimento tecnológico e simulação computacional, facilitando o acesso aos meus trabalhos acadêmicos e profissionais.

## 🛠️ Tecnologias utilizadas

- **React:** construção de interfaces e componentes reutilizáveis.
- **TypeScript:** desenvolvimento com tipagem estática.
- **Vite:** ambiente de desenvolvimento e ferramenta de build.
- **Oxlint:** análise estática e padronização do código.

## 📐 Principais áreas apresentadas

- **Modelagem 3D (CAD):** desenvolvimento de componentes e conjuntos mecânicos.
- **Análise estrutural (CAE/FEM):** estudos de cargas, tensões, deformações e comportamento estrutural.
- **Engenharia aeroespacial:** projetos e estudos relacionados a estruturas aeronáuticas e desenvolvimento de produto.
- **IoT e sistemas embarcados:** soluções envolvendo microcontroladores, sensores, comunicação e automação.

## 💻 Executando o projeto localmente

### Pré-requisitos

- [Node.js](https://nodejs.org/)
- npm

### Instalação

Clone este repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

Entre na pasta do projeto:

```bash
cd <NOME_DO_REPOSITORIO>
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
